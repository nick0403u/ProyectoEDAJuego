## RESUMEN
Este proyecto presenta el desarrollo de un videojuego educativo utilizando la biblioteca **Pyxel**, cuyo objetivo es reforzar el aprendizaje de estructuras de datos y algoritmos, específicamente grafos y árboles binarios. El videojuego simula un recorrido por los alrededores de la Universidad, donde los jugadores avanzan por nodos representativos y responden preguntas de tipo sí/no. Cada decisión genera un árbol binario de decisiones y, simultáneamente, se construye un grafo dinámico cuyo recorrido óptimo se calcula mediante el algoritmo de Kruskal. Los resultados obtenidos demuestran que la integración de conceptos teóricos en un entorno interactivo mejora significativamente la comprensión de los estudiantes.

**Palabras clave:** Grafos, Árboles Binarios, Pyxel, Kruskal, Videojuegos Educativos

---

## ABSTRACT
This project presents the development of an educational video game using the **Pyxel** library, aimed at reinforcing the learning of data structures and algorithms, specifically graphs and binary trees. The game simulates a journey around the university area where players move through nodes and answer yes/no questions. Each decision generates a binary decision tree and dynamically builds a graph, whose optimal path is calculated using Kruskal’s algorithm. The results show that integrating theoretical concepts into an interactive environment significantly improves student understanding.

**Keywords:** Graphs, Binary Trees, Pyxel, Kruskal, Educational Games

## 1. INTRODUCCIÓN
El aprendizaje de estructuras de datos y algoritmos es fundamental en la formación de ingenieros en sistemas. Sin embargo, estos temas suelen resultar abstractos para los estudiantes. Este proyecto propone una solución didáctica mediante el desarrollo de un videojuego educativo que permite aplicar grafos y árboles binarios en un entorno interactivo. Utilizando Pyxel, se logra representar visualmente el recorrido y la toma de decisiones, facilitando la comprensión práctica de los algoritmos estudiados.

### 1.1 Pregunta de investigación
¿De qué manera un videojuego educativo puede mejorar la comprensión de grafos y árboles binarios en estudiantes universitarios?

### 1.2 Objetivo General
Desarrollar un videojuego educativo en Python utilizando Pyxel que implemente grafos y árboles binarios para reforzar el aprendizaje de estructuras de datos.

### 1.3 Objetivos Específicos
- Implementar un grafo dinámico que represente el mapa del entorno.
- Aplicar el algoritmo de Kruskal para determinar el recorrido óptimo.
- Generar árboles binarios de decisión a partir de respuestas sí/no.
- Almacenar los resultados en archivos externos para su análisis.

### 1.4 Hipótesis
El uso de un videojuego educativo interactivo basado en Pyxel permitirá a los estudiantes comprender de manera más clara y práctica los conceptos de grafos y árboles binarios, en comparación con métodos tradicionales de enseñanza teórica.

---

## 2. METODOLOGÍA
La metodología empleada es de tipo experimental y práctica, basada en el desarrollo de software educativo.

### 2.1 Diseño del sistema
El videojuego fue diseñado en Python utilizando la biblioteca Pyxel para la interfaz gráfica. El sistema se divide en módulos para facilitar el mantenimiento del código.

### 2.2 Implementación en Pyxel
Pyxel se utilizó para gestionar la ventana gráfica, los eventos de teclado y el renderizado del mapa. Cada nodo del mapa representa un punto clave y al llegar a él se presenta una pregunta al jugador.

#### 2.2.1 Estructuras de datos utilizadas
- Grafos: Representan el mapa del recorrido.
- Árboles binarios: Almacenan las decisiones del jugador.
- Listas y diccionarios: Manejo de preguntas y nodos.

---

## 3. RESULTADOS Y DISCUSIÓN

### 3.1 Resultados
El videojuego permite recorrer correctamente el mapa, aplicar el algoritmo de Kruskal y generar árboles binarios de decisión en función de las respuestas de los jugadores. Los resultados se almacenan en archivos CSV para su posterior análisis.

### 3.2 Discusión
Los resultados evidencian que la integración de grafos y árboles binarios en un entorno interactivo facilita la comprensión de estos conceptos y mejora el aprendizaje práctico, incrementando la motivación del estudiante.

---

## 4. CONCLUSIONES
El proyecto demuestra que los videojuegos educativos son una herramienta efectiva para reforzar el aprendizaje de estructuras de datos. La implementación de grafos y árboles binarios mediante Pyxel permite una comprensión más intuitiva de algoritmos clásicos, fortaleciendo el pensamiento lógico y la toma de decisiones.
